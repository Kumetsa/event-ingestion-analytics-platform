# Event Ingestion & Analytics Platform

Backend platform for ingesting, validating, and analyzing event data using FastAPI, PostgreSQL, and ETL pipelines.

## Planned Features
- Event ingestion API
- Batch CSV import
- Data validation
- Analytics endpoints
- Anomaly detection

## Tech Stack
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pandera
- Docker

## Current Status
Milestone 1 - Project bootstrap in progress.
